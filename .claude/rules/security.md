# 安全规则

## 总原则

- 默认不信任外部输入
- 默认进行参数校验、权限校验、边界检查
- 默认保护敏感字段，禁止误暴露
- 默认不提交密钥、Token、密码、私钥等敏感信息

## 后端安全要求

- 所有外部输入必须校验
- 涉及登录态、权限、角色的接口必须做鉴权
- 敏感字段不得出现在响应 DTO 中
- 密码必须加密存储，禁止明文
- 更新操作必须使用字段白名单，防止越权更新
- 文件上传、导入、外部 URL 处理要做类型和范围限制
- 错误响应不得泄露数据库、内部路径、密钥等敏感信息
- 第三方回调、Webhook 必须校验来源或签名

## 前端安全要求

- 不在前端硬编码密钥、私密配置、固定 Token
- 不把敏感信息持久化到不安全存储中
- 路由权限、按钮权限必须配合后端鉴权，不可只依赖前端隐藏
- 渲染富文本、外部 HTML、动态链接时要防止 XSS
- 上传文件前应做基础校验

## 配置与密钥

- 敏感配置走环境变量或受控配置文件
- 禁止将密钥提交到仓库
- 不在日志中打印密码、Token、签名串、完整身份证号、银行卡号等

## 日志安全

- 日志中不得打印明文密码
- 日志中不得打印完整 Token
- 敏感字段应脱敏后再记录
- TraceID 可记录，但不能替代权限校验

## 禁止事项

- 明文保存密码
- 响应中返回敏感字段
- 更新接口直接整体更新请求 DTO
- 在前端硬编码私密配置
- 在日志中输出完整敏感信息
- 只做前端权限控制，不做后端鉴权
